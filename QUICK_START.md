# Quick Start: Adding Content to Sanity

Your schema is deployed! Now you need to add content. Here's how:

## Step 1: Access Sanity Studio

Go to: **https://sanity.io/manage**

Select your project: **Portfolio CMS** (Project ID: 48v38ttl)

## Step 2: Create Your First Content

### Start with Personal Information

1. Click **"+ Create"** button (top right) or look for **"Personal"** in the sidebar
2. Fill in your information:
   - **Name**: Your full name
   - **Designation**: e.g., "Software Developer"
   - **Description**: Your about me text
   - **Profile Image**: Upload your profile photo
   - **Email, Phone, Address**: Contact information
   - **Social Links**: GitHub, LinkedIn, Twitter URLs
   - **Resume**: Link to your resume PDF
3. Click **"Publish"** (top right)

### Add Projects

1. Click **"+ Create"** → Select **"Project"**
2. Fill in project details:
   - **Name**: Project title
   - **Slug**: Auto-generated (or customize)
   - **Description**: What the project does
   - **Image**: Upload project screenshot
   - **Tools**: Add technologies (press Enter after each)
   - **Role**: Your role (e.g., "Front-End Developer")
   - **Demo**: Live demo URL (optional)
   - **Code**: GitHub repository URL (optional)
   - **Featured**: Toggle if you want it featured
   - **Order**: Number (lower = appears first)
3. Click **"Publish"**

### Add Skills

1. Click **"+ Create"** → Select **"Skill"**
2. For each skill:
   - **Name**: e.g., "React", "TypeScript"
   - **Category**: Select from dropdown
   - **Order**: Display order
3. Click **"Publish"**
4. Repeat for all your skills

### Add Experience

1. Click **"+ Create"** → Select **"Experience"**
2. Fill in:
   - **Title**: Job title
   - **Company**: Company name
   - **Duration**: e.g., "(Jan 2024 - Present)"
   - **Start Date**: Actual start date
   - **End Date**: Leave empty if current job
   - **Description**: What you did
   - **Order**: Display order
3. Click **"Publish"**

## Step 3: View Your Portfolio

After adding content, your portfolio at `http://localhost:3000` will automatically display it!

## Tips

- **Publish** is important - only published content appears on your site
- Use **Order** fields to control display sequence
- Upload images directly to Sanity (they'll be optimized automatically)
- You can edit and republish anytime

## Need Help?

- Check the sidebar for all content types
- Look for the "+" button to create new content
- Make sure to click "Publish" after creating content
